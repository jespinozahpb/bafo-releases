# BAFO releases

Install files for BAFO, a Plex app for Android TV and Fire TV. This repo holds release files only.

Install on a Fire TV with the Downloader app. In Downloader's address box, type the code:

    9611022

or this link (both always give the newest version):

https://jespinozahpb.github.io/bafo-releases/

After that, BAFO updates itself from Settings > About.

## Optional: a free TMDB key

BAFO works with Plex alone. A free TMDB key adds posters, trailers, suggestions and the streaming tab.

1. Make a free account at https://www.themoviedb.org
2. Open Settings, then API: https://www.themoviedb.org/settings/api
3. Copy the API Read Access Token (or API Key), then in BAFO open Settings > Accounts > TMDB > Connect and paste or type it.

With Google sync on, your other TVs get the key on their own.
