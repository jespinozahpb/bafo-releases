# BAFO releases

Install files for BAFO, a Plex app for Android TV and Fire TV. This repo holds release files only.

Install on a Fire TV with the Downloader app, using this link (always the newest version):

https://github.com/jespinozahpb/bafo-releases/releases/latest/download/bafo.apk

After that, BAFO updates itself from Settings > About.
