# BAFO releases

Install files for BAFO, a Plex app for Android TV and Fire TV. This repo holds release files only.

Install on a Fire TV with the Downloader app. In Downloader's address box, type the code:

    9611022

or this link (both always give the newest version):

https://jespinozahpb.github.io/bafo-releases/

After that, BAFO updates itself from Settings > About.
